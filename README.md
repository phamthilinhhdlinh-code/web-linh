# Hệ thống Quản lý Học sinh Môn KHTN - Cô Linh

Dự án Hệ thống Theo Dõi Thi Đua Nhóm & Tự Động Chốt Điểm Khoa Học Tự Nhiên dành cho Trường THCS Hoàng Diệu.

## Hướng dẫn chạy dự án:
1. Cài đặt Python (phiên bản 3.8 trở lên).
2. Mở terminal tại thư mục dự án và chạy lệnh:
   ```bash
   python app.py
   ```
3. Mở trình duyệt và truy cập: `http://127.0.0.1:5000`
